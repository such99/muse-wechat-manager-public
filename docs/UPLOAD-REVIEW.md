# r10 上传与隐私检查

检查日期：2026-10-14。公开范围为独立仓库的干净源码快照及 r10 Release 资产，原开发仓库保持私有。新仓库不继承开发仓库旧历史。

- 源码使用通用账号称呼，确认协议为 `confirm_owner`，正式绑定为 `owner`。
- 六份示例配置未登录、关闭自启。发布清单排除运行数据、密钥、DPAPI、聊天、浏览器配置、私人截图和本机修复报告。
- 便携包通过白名单构建，逐文件核对 manifest。源码与对应 ZIP 一致，上游固定文件哈希和许可保留。
- 凭据模式命中需逐项核验，仅接受明确的假测试值或第三方自测/文档示例；不能以扫描通过证明所有秘密都不存在。
- r10 随包提供 91 项假凭据/离线/独立本机测试；EXE 集成结果见 Release 的 `bundle-verification.json`。
- 41 个锁定依赖版本的 OSV 查询未匹配已知漏洞；查询日期为本报告日期，不构成未知漏洞保证。
- 模式扫描与人工检查的范围仅限分发源码和干净包。任何实际登录或使用后的目录都需要另行检查，禁止原样分享。

ZIP SHA256 见 `distribution/SHA256SUMS.txt` 及 Release 同名文件。完整文件清单和哈希在 Release 的 `manifest.json` 中。
