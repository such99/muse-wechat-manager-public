# 公开发布与维护

当前公开版本为 r10 预览版，使用独立仓库和干净源码历史。原开发仓库保持私有，公开仓库不使用 fork，也不推送旧历史、已使用的安装目录或本机修复日志。

每版从明确的源码清单、固定上游文件与依赖构建全新 ZIP；二进制只在 Releases 保存，Git 内只保留源码和 SHA256 校验值。随包提供 manifest、第三方许可、手册和可重复执行的测试。私下安全报告见 SECURITY.md。

r10 合并 2026-10-13 卡片过滤与 2026-10-14 发送门槛修改。当前 91 项假数据/本机测试通过；真实手机使用反馈来自此前 r7 修订版，不替代 r10 实测。六组真实账号并行、MiMo、真实过期恢复、新机器开发环境重建仍待验；Windows CI 尚未配置。

公开可见不新增开源许可，自有代码保留现有权利；第三方原许可不变，见 RIGHTS.md。以后如选择开源许可证，需另行明确授权范围。

维护时保留版本变更、上游锁和资产哈希。聊天、凭据、登录会话和私人截图只保存在使用者本机。历史测试、用户反馈与当前版本受控测试分别记录。
